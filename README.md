## About me

I’m a **Web & Mobile Application Development student at PSE Institute** in Phnom Penh, Cambodia. I’m working toward a full-stack developer role, with a particular interest in APIs and databases.

I like the decisions behind a simple screen. In **AquaTrack**, even a “Log water” button raises a backend question. If someone records a drink just before midnight, which day should it count toward? I built the daily totals around the user’s time zone.
