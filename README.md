## About me

I’m **Somnang Dara**, a Web & Mobile Application Development student at **PSE Institute** in Phnom Penh, Cambodia. I’m working toward a backend-focused full-stack role where I can design APIs and the databases behind them.

In Smart Locker, two people can see the same free locker on their screens. I lock the locker’s database row before checking availability and assigning it, all in one Laravel transaction. That way, only one person gets the access code. [Read the assignment logic][assignment]
